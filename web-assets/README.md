# Website assets

Export the paper figures directly from the original figure files and place them
in this directory. The page automatically loads these filenames:

| Page placement | Source | Filename |
| --- | --- | --- |
| Overview / teaser | Fig. 1 | `fig-01-overview.webp` |
| Method pipeline | Fig. 3 | `fig-03-pipeline.webp` |
| Complex geometry result | Fig. 4 | `fig-04-femur.webp` |
| Distortion ablation result | Fig. 10 | `fig-10-distortion-ablation.webp` |
| Scalability result | Fig. 15 | `fig-15-scalability.webp` |
| Physical validation | Fig. 17 | `fig-17-physical-models.webp` |

Use WebP in the sRGB color space. A width of 1800–2400 px is sufficient for
all figures. Keep each file below approximately 1 MB where possible.

Optional institution logos can be added later as:

- `logo-digital-manufacturing-lab.svg`
- `logo-university-of-manchester.svg`
